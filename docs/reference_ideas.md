# References and easter eggs

These are original Range Club details informed by things Kevin likes. Keep them
small enough that the game still makes sense to someone who misses every nod.
The current range contains two small signs, an optional case file, and three
character/build presets.
The rival encounter and fuller character presentation belong to later slices.

## Mega Man X — earnest future drama

- **In the range now:** Case File 3909 dates the setting to **21XX** and treats
  an ordinary practice lane as a matter of institutional urgency. The file is
  optional, so repeated runs start quickly.
- **Later:** an opening text crawl can build on this tone once the game has a
  stronger story hook. Keep it skippable and write original world history.

## Lucas Pope — visual sensibility and a quiet marker

- **In the range now:** `LANE 3909` is a background sign. 3909 is a nod to Pope's
  studio, not a gameplay clue.
- **In the range now:** Case File 3909 uses a restrained record layout and an
  invented Range Authority to make the club's beginning feel absurdly official.
- **Later, if the results screen needs it:** try a restrained scorecard or archive
  record with strong typography and a limited palette. Let the record help the
  player read each shot and build choice. Test that it fits Range Club's own
  identity instead of copying a particular game's screen, stamps, or 1-bit art.
- **Source:** [Lucas Pope's games](https://3909.co/) and his
  [account of developing *Obra Dinn*'s visual style](https://blog.playstation.com/archive/2019/10/17/lucas-pope-on-return-of-the-obra-dinns-art-style).

## Hunter × Hunter — the fish siblings

- **In the range now:** a small `NO FISH DARTS` sign on the backstop and a
  case-file annex denying a shared permit to two aquatic applicants. These are
  jokes, not promises of a new weapon or attack.
- **Later, only if a rival encounter earns a place:** a pair of original aquatic
  rivals could alternate throws against a shared board. A visible, predictable
  pattern would echo the fish and darts premise without reusing the anime's
  characters, names, story, designs, or exact ability.
- **Source:** [the anime's Chimera Ant character page](https://www.ntv.co.jp/hunterhunter/character/).
  The specific fish-dart association is Kevin's reference; no new gameplay fact
  depends on a precise account of the scene.

## Yusuf Dikeç — character and build philosophy

- **In the range now:** the original veteran marksman **The Natural** uses the
  Bare Rig and rewards an unfocused bullseye. Maera the rune smith uses Focus
  to tighten the landing circle; Vey the arc scout moves aim quickly and earns
  a bonus for fast, accurate shots. All three are selectable from the start.
  These presets make the handling tradeoff part of each marksman's identity.
  The case file alludes to a veteran declining the prescribed equipment.
- **Later character presentation:** give The Natural an original portrait and
  dialogue about a clear release and sparse kit. A credits or inspiration note
  can name Dikeç directly. Air-pistol shooting is the real-world inspiration;
  the range mechanic is a deliberate translation for this game.
- **Source:** the [International Shooting Sport Federation's account of
  Dikeç's Paris 2024 appearance](https://www.issf-sports.org/news/4439) and
  [official mixed-team result](https://www.issf-sports.org/competitions/results?catId=1&compId=2728&ei=124&eiv=2&view=rsList).
